# Artificial Life: Conway's Game of Life

An interactive, Matrix-styled Conway's Game of Life: click cells to seed a pattern, randomize, start, pause and control the speed, with an explanation of the rules and of why simple rules produce life-like emergent behaviour.

**[Live demo](https://raultovar-space.github.io/game-of-life/)**

Originally built as a React/TypeScript app in Lovable; this repository is a dependency-free single-file version (`index.html`, canvas + vanilla JS) with the same rules, controls and design.
